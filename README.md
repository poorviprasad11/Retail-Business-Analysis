# Retail Business Analysis

Retail Business Analysis using Python, SQL and Tableau.

## Project Overview

This project analyzes retail sales data to identify trends, profitability, discount impact, category performance, regional performance, and top and bottom performing products.

## Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- SQL
- Tableau Public

## Analysis Performed

- Sales and Profit Analysis
- Profit Margin Analysis
- Category and Sub-Category Analysis
- Region-wise Performance
- Discount vs Profit Analysis
- Monthly Sales Trend
- Top 10 Products by Profit
- Bottom 10 Products by Profit

## Conclusion

The analysis provides insights into sales, profitability, discounts, regional performance, product performance, and seasonal trends to support better retail business decisions.
